# 筆順小練習

給國小一年級用的筆順練習網站，iPad 用手指或觸控筆寫。流程：① 看動畫 → ② 描 → ③ 自己寫。
寫完一個字集一點，老師在後台看全班練習狀況、改生字和學生名單。

筆順資料來源：中華民國教育部《國字標準字體筆順學習網》，依 CC BY-NC-ND 3.0 臺灣授權，原樣使用（不修改、限非商業）。

## 架構

```
GitHub Pages（這個 repo）              Google 試算表 + Apps Script（班級資料服務）
- 學生練習、老師後台的網頁               - 學生名單、生字表、練習紀錄、設定
- 預設字表 words.csv（康軒一年級）       - 代替網站向教育部取得新字的筆順
- 預設字的筆順 data/*.xml
```

班級資料服務的位址不放在 repo 裡（網站是公開的），而是放在 QR Code／老師連結的 `#w=<部署 ID>`。
`#` 後面的部分不會送到伺服器。沒有這個連結的人打開網站，只能用預設字表練習，看不到名單。

## 第一次設定（開發者做一次）

1. **部署網站**：GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`。
2. **建立班級資料服務**
   1. 新增一份 Google 試算表（可以先放學生名單：第一列 `座號`、`姓名`）。
   2. 「擴充功能 → Apps Script」→ 貼上 `apps-script/Code.gs` 全部內容 → 存檔。
   3. 「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」→ 執行身分「我」、誰可以存取「所有人」→ 部署 → 授權。
   4. 複製「網頁應用程式」網址。
3. **連接**：打開網站 → 右上角「老師後台」→ 貼上網址 → 設定老師密碼。
4. 後台「生字」可匯入康軒一年級字表；「學生名單」可整份貼上；「QR Code」印給學生。
5. 把 QR Code 的連結給老師加入書籤，老師就從這個連結進後台。

更新 `Code.gs` 後：Apps Script「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」（網址不變）。

## 老師後台（網站右上角「老師後台」）

| 分頁 | 內容 |
|---|---|
| 練習狀況 | 全班近 7 天練習狀況（圓餅圖＋沒練習的名單）、每天練習人數、最常寫錯的字、每人點數 |
| 生字 | 新增/刪除課次與生字、調整順序；注音自動帶入（萌典），破音字可改 |
| 學生名單 | 新增/修改/刪除；可從試算表整份貼上 |
| QR Code | 全班共用的 QR Code，可列印 |
| 設定 | 班級名稱、幾點一張集點卡；移除這台裝置的連線 |

密碼存在試算表的「設定」工作表；忘記或要改密碼請直接在那裡修改。

## 集點規則

「寫」的階段完成一個字 = 1 點，同一個字一天只算 1 點，預設 20 點一張集點卡。
沒有網路時紀錄先存在 iPad，連上網後自動補送，不會重複記錄。

## 開發

- 本機預覽：`python3 -m http.server 8000`，開 http://localhost:8000
- 手寫判斷測試：`node tools/judge.test.js`
- 資料服務測試：`node tools/gas-mock.js`
- 模擬資料服務：`node tools/gas-mock.js serve`（http://127.0.0.1:8090/，到「老師後台」貼上這個網址）
- 預先下載預設字的筆順：`python3 tools/fetch_moe.py`
